### Verification Commands
```bash
# 1. View Release Metadata
gh release view v0.1.0 --repo SumitDalavi/prompt-versioning-ab-testing

gh release download v0.1.0 --repo SumitDalavi/prompt-versioning-ab-testing --pattern "*.tar.gz" --pattern "checksums.txt"

# 3. Inspect SPDX SBOM
```
